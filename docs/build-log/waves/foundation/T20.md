## What changed

- **Why Arabic sessions saw English titles.** Listing rows and detail already used the caller's
  stored `users.language`. T14's Arabic screenshots signed in as Sara, whose stored language is
  `en`; the Playwright projects only set the locale cookie (the account panel's switch does save
  the language through `PATCH /auth/me`). The real API gaps were elsewhere: `toReminder` used the
  English `listingLabel` (reminders list/create/edit/done, owner timeline, today's ad tasks) and
  the trash list used it too. Fixed in one place: `toReminder(row, now, language)` takes the
  reader's language (`RemindersService.shapeFor` looks it up once per request, inside `tx` when
  there is one); `listingLabel` / `photoLabel` take a language (default `en`, the activity-log
  snapshot) and `TrashRepository.list` passes the reader's. Photo labels: "Photo N" / "صورة N".
- `/me/today`: `RemindersService.today` returns `counts { overdue, dueToday, adTasks,
  remindersOpen }` (count queries on the same `where` as each list); `CallsService.today` returns
  `outcomeMissingTotal` (the page's count). `MeService` assembles them.
- `GET /reminders?ownerId=` — every reminder on that owner, whoever's (as the owner timeline
  shows); the owner must be live and the caller's or the caller holds `owners.viewAll`, else 404.
  `?listingId=` — same for a listing, with `listings.manageAll` as the bypass (a member may open
  any listing, but its reminders are its member's, like the owner phone). With either filter the
  default "own reminders" filter is dropped; `memberId`, `state`, `when`, `kind`, `unassigned`
  still combine (another member's `memberId` still needs `analytics.view`).
- `addToOwner` / `addListingTask` now return nothing (their shaped reminder was never used).
- Docs: spec (Listing shape, title note, `/me/today` and `/reminders` rows) and BUSINESS_LOGIC
  (owner/listing reminder views, today totals, titles in the reader's language).
- Web: only test fixtures (`call-flow.test.tsx` counts, `listings/test-fixtures.tsx`
  `adTakeDownOpen`) so web typecheck stays green.
