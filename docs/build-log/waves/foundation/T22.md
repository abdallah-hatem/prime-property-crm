## What changed

- **Bottom tab bar** (`shell/app-shell.tsx`): every tab is icon over label in four equal columns
  (11 px bold label, `min-w-0` + truncate as a guard), so "Listings" / "الوحدات" fit at 320 px. A
  `short:` variant (`@media (max-height: 30rem)`, defined in `globals.css`) hides the labels
  (`sr-only`, the accessible name stays), slims the tab to 44 px and lowers the bar: 66 → 54 px at
  640×400 (200% zoom). The main area's bottom padding follows.
- **Text direction**: `components/user-text.tsx` (`<UserText>`: a `<bdi>` for inline runs, or
  `dir="auto"` + `text-start` on a block via `as="p"`) and `lib/bidi.ts` (`isolate()`: FSI…PDI for
  a typed value inside a translated sentence string). Used for listing title, place, description,
  address, assignee and owner name on the listing detail; note bodies and authors; reminder names
  and notes (table) and every OwnerRow (Today, reminders, owner rows); activity actor, summary and
  detail values, with `isolate()` on the names/labels inside the activity sentences; missing-outcome
  card and the phone-chooser sentence; owners list, listing cards and search rows, outcome sheet
  owner, listing form owner, account name in the shell; users, user sheet, roles, trash and imports
  lists (the plain `<bdi>` wrappers there now use `<UserText>`). Owner detail (T23's file) was left.
- **Reminders**: the table's cells don't wrap, which pushed the actions past the card's scroll edge.
  The note column now wraps to two lines and the actions cell wraps (`whitespace-normal`, `w-64`); the system reason fills it
  beside Edit in one nowrap row in both languages; on phone cards a system reminder's reason is the
  row's second line (`ReminderRow showSystemReason`) and the action is just the Edit icon, so the
  title keeps its width.
- **Placeholders**: new `--placeholder` token (lighter than `muted-foreground`, still AA on a card
  in both themes) on `Input` / `Textarea`. Sample placeholders start with "e.g." / "مثال:" (a right-
  to-left mark after the colon when the Arabic sample is Latin: email, URL). The admin password
  placeholder is "At least 8 characters" / "8 أحرف على الأقل". `ui/select.tsx` belongs to T23 and
  was not edited; its trigger already uses `muted-foreground` for the placeholder.
- **44 px targets**: `Button` gets an invisible hit area (`after:-inset-1`) below md, so `sm`
  (36 px) and `icon-sm` reach 44 px without growing; `link` buttons get `min-h-11` on phones. The
  avatar is 44 px. The owner phone link on the listing is a 44 px row on phones.
- **Dark primary**: `--primary` #5465f8 → `--primary-end` #7350f0 with white text (4.6:1 / 5.1:1);
  new `--link` token (light = primary, dark = #a3adff) for primary-hued text (`text-link`: link
  buttons, import links, calendar today, row hovers, the status-menu check); the ring stays the
  lighter indigo.
- **Gutter**: `html` uses `scrollbar-gutter: auto`, `stable` only under `(hover: hover) and
  (pointer: fine)`.
- **Nits**: `components/back-link.tsx` (`BackLink`, the arrow mirrors) on the import job page, the
  import wizard (moved above the header) and the analytics member page. "Mark taken down" is in
  the ad action group: outline while the home is available, soft when it isn't (`data-testid
  mark-taken-down`). New `destructive-outline` button variant for destructive entry points (user
  sheet Deactivate, listing Delete); confirm dialogs keep the filled `destructive`.
- Tests: `user-text.test.tsx` (inline isolation, block `dir="auto"`, `isolate()`),
  `admin/users/password-placeholder.test.ts` (the password placeholder is a rule with words and the
  minimum length, never a one-token password); `call-flow.test.tsx` expects the isolated name.
- `docs/DESIGN.md`: roles for `link`, `placeholder`, the two destructive styles, dark primary.
