## What shipped

- **Manifest** `apps/web/src/app/manifest.ts`: "Prime CRM", `id`/`start_url` `/today`, scope `/`,
  standalone, `dir: auto`, light page colour for `theme_color`/`background_color` (constants in
  `src/lib/pwa.ts`, mirroring the `--background` tokens). Static: browsers fetch manifests without
  cookies, so it can't follow the user's language; the brand name reads the same in Arabic UI.
- **Icons** (A1: indigo-cobalt → violet tile, white "P" with a roof and a house-shaped counter, two
  call waves): `apps/web/public/icons/icon.svg`, `icon-192.png`, `icon-512.png`,
  `icon-maskable-512.png` (mark inside the 80 % safe zone), `apple-touch-icon.png` (180, full
  bleed), `apps/web/public/favicon.ico` (16/32/48). Regenerate: `node scripts/generate-icons.mjs`
  in apps/web (uses `sharp`, already installed as Next's optional dependency).
- **Viewport / status bar** (`src/app/layout.tsx`): `viewport-fit=cover`, `color-scheme`,
  theme-color per `prefers-color-scheme`; `ThemeColorSync` (`src/components/theme-color-sync.tsx`)
  rewrites both metas to the in-app theme once known, so Dark on a light phone gets a dark bar.
  `appleWebApp` capable, status bar `default`; telephone auto-detection off.
- **Mobile-native** (`globals.css`, no token changes): `hover:` redefined to
  `(hover: hover) and (pointer: fine)` (verified in the built CSS); tap highlight off,
  `text-size-adjust: 100%`; `.scrollbar-clean` scrollers other than the page get
  `overscroll-behavior: contain` (page keeps browser pull-to-refresh); 16 px floor for fields under
  md; `px-safe-4` utility. Shell: `:active` states on tabs, sidebar links, More rows, account
  triggers; landscape safe-area side padding on main, top bar and the tab bar; sidebar nav
  `overscroll-contain`; toasts offset below the status bar. Full heights were already `dvh`.
- **Install card** (`src/components/shell/install-card.tsx`, store in `src/lib/install-prompt.ts`),
  in `AccountPanel` (account menu and More page): replays `beforeinstallprompt` (captured at module
  load so an early event isn't lost); iOS Safari (incl. iPadOS) gets Share → Add to Home Screen
  steps; hidden when standalone, after `appinstalled`, or once dismissed (`localStorage`
  `prime.install-card.dismissed`, every access in try/catch). Strings `install.*` in en/ar.
- **No service worker.** Every screen is auth-gated, server-rendered data; caching it would risk
  showing one user's data after sign-out, and an offline page adds little to a phone-and-call
  workflow. Chrome no longer requires a service worker for installability.
