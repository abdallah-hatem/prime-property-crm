## Asked by T17 (analytics)

- `apiFetch` `response` option: `'envelope'` (default), `'raw'` (the Blob handshake), `'binary'`
  (a file: `BinaryFile { base64, contentType, fileName }`, the name read from
  `Content-Disposition`, `filename*` UTF-8 first). A binary call gets the same 401 path as JSON:
  refreshed in place and retried once from a server action; a refusal reads the error envelope.
  For T17's `export-actions.ts` after the merge.
- `ui/calendar.tsx`: month arrows flip under RTL (`flip-rtl`; react-day-picker always asks for
  left/right icons while the buttons swap sides); `weekStartsOn`, default Saturday.
- `filter-chips.tsx`: `trailing` node after the pills (a "Custom" pill).
- `homeFor`: `analytics.view` → `/analytics`, everyone else `/today` (proxy test, routes test and
  `e2e/smoke.spec.ts` updated: the admin now lands on `/analytics`).
- Tests: `lib/api-binary.test.ts` (bytes + UTF-8 name, error code, refresh-and-retry, failed
  refresh), Calendar (Saturday default, override, Arabic arrows move to the previous month),
  FilterChips trailing slot, `homeFor` per role.
