## Decisions and deviations

- **No `GET /imports/:id`** in the contract: `GET_IMPORT` reads `GET /imports` pages (up to 10 ×
  20) to find a job; older jobs 404 on the detail page.
- `/imports` is gated by `owners.import` in `ADMIN_ROUTES` (T12), so a listings-only importer
  (listings.create without owners.import) can't reach the wizard yet, although the wizard supports
  the Listings kind.
- Status filter is single-choice pills (like T13), though the API takes several.
- Users with owners.assign but not owners.viewAll (Team lead) get the admin table: the rows are
  their own owners (API scoping) while "select all / next N" reach every owner by id, as the
  business logic says.
- FAILED import status uses the warning chip (red is reserved for overdue / destructive).
